# 减灶 · 原创剪影动画

118秒，1920×1080，原生时间轴60fps。Hypit官方Runtime渲染，原始48kHz立体声WAV音效；没有旁白或BGM，人声由作者后期完成。

据《史记·孙子吴起列传》改编，具体动作与亲兵“再探”的短对白为艺术化演绎，非史料原话。灶数不等同人数或死亡人数。
